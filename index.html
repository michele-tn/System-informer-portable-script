01 / GET RUNNING

From download to desktop.

Save the script in a writable local folder. It stores the ZIP and the portable application beside itself unless you choose another destination.

1

Save the script

Download Start-SystemInformer.ps1. If your browser opens it as text, save it with the exact .ps1 extension. You can also download the double-click launcher; keep both files together.

2

Open PowerShell in that folder

In File Explorer, open your folder, type powershell in the address bar and press Enter. Paste the command below.

3

Approve Windows elevation

Accept the UAC prompt or provide an administrator account. The elevated script checks the latest stable release, verifies the ZIP, extracts it and starts a new elevated instance.

POWERSHELL / QUICK START
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\Start-SystemInformer.ps1"

The execution-policy option applies to this PowerShell process. It does not change your machine's saved policy or grant administrator privileges. UAC handles elevation. Organization policy may still block execution.

Verify the script archive with Python 3

Save the ZIP and checksum file together. From that folder, run the following command if Python 3 is installed. Compare the printed digest with the checksum above or the downloaded checksum file.

python -c "import hashlib; from pathlib import Path; print(hashlib.sha3_256(Path('Start-SystemInformer.zip').read_bytes()).hexdigest())"

Use SHA3-256, not SHA-256: they are different algorithms. An older ZIP may have a different checksum after the script is updated.

This SHA3-256 identifies the compressed script package. The script separately checks the latest stable portable System Informer binary ZIP against SourceForge's SHA-256 before extraction. Setup EXEs are never selected.

03 / THE WORKFLOW

A download you can inspect.

DISCOVER

Latest stable, every run.

The script reads the official SourceForge file listing and compares version numbers of portable ZIPs. If discovery fails, it stops rather than silently using an old release.

VERIFY

Hash before extraction.

The expected SHA-256 comes from the selected file's SourceForge page. A matching ZIP is reused; a mismatch is never extracted or launched.

PRESERVE

A folder for each version.

Each release gets its own folder. Existing prepared folders and settings are reused. Old versions remain available; settings are not migrated automatically.

ELEVATE

An administrator instance.

The script checks the Windows administrator token and relaunches through UAC when needed. It requests a new application instance to avoid forwarding to an unelevated one.

Why the original download failed

https://sourceforge.net points to the homepage, not an archive. Saving HTML under a .zip name does not convert it into a ZIP. Some download pages also return an HTML timed redirect; -MaximumRedirection handles HTTP redirects, but not that HTML behavior. The script follows a recognized HTTPS SourceForge refresh and verifies the resulting file.

What SHA-256 verification proves

It checks that the archive matches the hash published by SourceForge. It is not an independent security audit or a publisher signature check. Download failures, missing hashes and unexpected redirects stop the operation.

Move the whole folder.

The script resolves its own location, so moving the workspace keeps the default paths working. You will need administrator approval on the next Windows computer.

The ZIP is retained. The JSON settings file lives beside the executable for the selected architecture. The manifest records the release, hash, relative executable path and check time.

Portable means no setup installer is run. Windows, the application or its driver may still create runtime system state. The launcher checks online each time; direct executable use does not check for updates or elevate automatically.

05 / GET UNSTUCK

Find a fix, fast.

6 topics available

PowerShell says scripts are disabled

Use the quick-start command above, which sets execution policy for that process. If a managed policy still blocks it, ask your administrator for an approved execution method. The script does not change Group Policy.

UAC elevation was cancelled or denied

Run again and approve the Windows administrator prompt. Standard accounts need administrator credentials. The script cannot bypass UAC or account restrictions.

HTML was downloaded instead of the ZIP

The script follows recognized SourceForge timed redirects automatically. If no redirect is present, the server may be returning a challenge or error page. Check the official download in your browser and retry later; do not rename the page and extract it.

SHA-256 does not match, or no hash is available

The script stops before extraction. Retry with a working connection and check the selected file's official SourceForge page. Never remove the verification step to force a failed archive to run.

An incomplete folder exists, or the directory is locked

Close another running copy of this script if one exists. The lock file remains on disk, but only an open file handle locks it. If extraction was interrupted, rename the incomplete version folder and retry. Its files are preserved for inspection.

The application exits, or Windows blocks it

Read the script's startup error and any Windows message. Check Windows compatibility and your organization's application policy. The script does not disable antivirus, application controls or driver protections. Full administrator rights do not override those controls.

06 / SHARE THE GUIDE

Ready for GitHub Pages.

This guide is plain HTML5, CSS and JavaScript. No build tool, account connection or external font is required. All asset and download links are relative, including on repository project sites.

  1. Copy the contents of the complete GoLive folder into the root of your GitHub publishing branch, including assets, downloads and .nojekyll.
  2. Commit and push the files to your publishing branch.
  3. Open Settings → Pages → Build and deployment. Select Deploy from a branch, choose your branch and / (root), then save.
  4. Wait for GitHub's deployment to complete and open the published site. Check the script download and Copy command buttons.

This package is ready to publish. Creating local files does not publish a GitHub Pages site. When updating the script, rebuild the script ZIP, its SHA3-256 checksum file and the displayed digest together.
